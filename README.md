# RunDisplay Extension

RunDisplay Extension is a Visual Studio extension that adds a custom ToolWindow with a built-in timer and visual elements to track code execution in real time.

## ✨ Features
- Integrated timer to monitor runtime sessions.
- Lightweight visual interface with smooth animations.
- Optimized design to avoid performance impact.
- Default theme included, with plans to add more themes in future releases.

## ❓ Why?

When working across multiple screens, I often felt concerned about how a plain window filled with lines of text might appear — to programmers and non-programmers alike, whether colleagues, managers, or friends. It can look inactive or confusing, especially when waiting for code execution to complete.

With several screens in use, it was also difficult to notice when the code hit a breakpoint, encountered an error, or finished running. While I usually configure notifications for end users, I wanted a clearer way to visualize this process during development.

RunDisplay was created to make code execution more visible without being distracting. The subtle visual feedback and integrated stopwatch help track progress and compare runtime against previous executions, all while maintaining a lightweight and professional interface.
